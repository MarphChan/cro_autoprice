# 字段说明

本文档基于 [src/shared/schema.ts](file:///Volumes/SANDISK%20ELE/CRO-Sales/innostar_demo_1008/src/shared/schema.ts) 整理，对应示例数据见 [data/records/expertExample.json](file:///Volumes/SANDISK%20ELE/CRO-Sales/innostar_demo_1008/data/records/expertExample.json)。

## 使用说明

- `values` 中的键名必须使用字段 `id`
- `select` 填单个字符串，值应使用选项里的 `value`
- `multiselect` 填字符串数组，数组成员应使用选项里的 `value`
- `number` 在当前记录结构中也按字符串保存
- `required = 是` 表示模板必填字段

## 一、委托方信息

| 字段ID | 字段名称 | 类型 | 必填 | 说明/可选值 |
| --- | --- | --- | --- | --- |
| `client.companyName` | 单位名称 | `text` | 是 | 委托方公司全称 |
| `client.contactName` | 联系人姓名 | `text` | 是 | 对接人姓名 |
| `client.jobTitle` | 职位 | `text` | 否 | 联系人岗位 |
| `client.phoneNumber` | 手机号 | `phone` | 否 | 手机号码 |
| `client.email` | 邮箱 | `email` | 否 | 联系邮箱 |
| `client.address` | 地址 | `textarea` | 否 | 公司或办公地址 |
